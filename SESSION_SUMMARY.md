## Problems Identified

### P1. Path 6 Was Silently Dead (FIXED)

**Root cause:** `TopologyEdge(from_idx=, to_idx=, flow_type=)` — wrong constructor signature. The Rust PyO3 constructor is `TopologyEdge(edge_type)` with `add_edge(from, to, edge)`.

**Impact:** Every SAGE+Path6 run caught the TypeError silently and fell back to Rust templates. **No benchmark ever used the trained model.**

**Fix:** `pipeline.py` line 392 — corrected constructor + `TopologyGraph("sequential")` instead of `TopologyGraph("learned_policy")`.

**Status:** FIXED (commit `6375ddc`)

### P2. GRPO via TRL `environment_factory` Destroyed Model Format (NOT FIXABLE)

**Root cause:** TRL's `environment_factory` takes over generation format. It injects tool schemas via the model's native chat template. Qwen3's chat template has thinking mode (`<think>`) enabled by default. The model optimized for TRL's internal tool format, not our `<tool_call>` wrapper.

**Impact:** Training reward was 1.463 (high!) but the model generates `<think>` at inference instead of `<tool_call>`. N1 eval: 0.115 (down from 0.922).

**Evidence:**
- AgentConductor (arXiv 2602.17100): used plain `reward_funcs`, NOT `environment_factory`
- The Conductor (Sakana AI, ICLR 2026): same — plain GRPO with format parsing
- Both validated: SFT teaches format, GRPO optimizes quality via reward functions

**Fix for V2.1:** Use TRL GRPOTrainer with `reward_funcs` only (no `environment_factory`, no `tools`). The model generates `<tool_call>` freely, reward functions parse and evaluate. This is `train_local_qwen3_4b.py` with `SAGE_VERL_EXEC=1`.

**Status:** GRPO checkpoint DISCARDED. Lesson saved in memory (`feedback_grpo_v2_lessons.md`).

### P3. V2 SFT Regressed vs Phase C (ACTIVE — NOT FIXED)

**Root cause (hypothesis):** The V2 SFT dataset (8633 entries) is 60% `adapt_topology` decisions (5139 entries) and only 22% `create_topology` (1898 entries). The model may have overfit to adaptation format at the expense of topology generation quality.

**Evidence:**
- Phase C: 40% MASBENCH depth (adapter: `toolcall_qwen3_4b_phase_c`)
- V2 SFT: 20% MASBENCH depth (adapter: `toolcall_qwen3_4b_v2`)
- V2 generates 3-node topologies consistently (vs Phase C's 3-5 nodes)
- 5/10 tasks produced empty answers (nodes timeout or produce no output)

**Additional factors:**
- V2 data includes simulated episodic memory context (template text, not real) — may confuse the model
- `[Complexity: S1/S2/S3]` prefix not in Phase C data — model may not have learned to use it effectively
- V2 adapter tokenizer has broken `extra_special_tokens` (list vs dict) — cross-version incompatibility

**Status:** ACTIVE. Phase C remains the best model.

### P4. Inter-Node Communication Truncated to 500 chars

**File:** `sage-python/src/sage/verl/topology_env.py` line 605, `sage-python/src/sage/topology/runner.py` line ~240

**Root cause:** Predecessor output is truncated to 500 chars before injection into successor node's context. A coder producing 80 lines of code → the reviewer sees only the first 10 lines.

**Impact:** Reviewers can't verify edge cases, return values, or bugs at end of code. Multi-node topologies lose their value.

**Fix:** Increase to 4000 chars (or model's context limit). 2-line change.

**Status:** NOT FIXED (deferred to V2.1)

### P5. No Bidirectional Agent Communication

**Root cause:** Topology execution is a single DAG pass — A→B but never B→A. No debate, no iteration.

**Impact:** Reviewer can't ask coder to fix bugs. Only forward-passing information.

**Fix:** Add a "debate" execution mode with N rounds of exchange. Requires new edge type and executor changes.

**Status:** NOT FIXED (deferred to V3)

## Lessons Learned

1. **NEVER use TRL `environment_factory` for models with custom output formats.** It takes over generation format and destroys what SFT taught. Use plain `reward_funcs`.

2. **Custom GRPO training loops are fragile.** Manual gradient computation, log_prob tracking, and multi-turn orchestration broke 3 times. Use TRL GRPOTrainer — it handles everything.

3. **Always test the full pipeline end-to-end before benchmarking.** Path 6 was silently dead for weeks (TopologyEdge wrong constructor). Every benchmark used template fallback, not the trained model.

4. **Data balance matters.** 60% adapt_topology in V2 data degraded topology generation quality.

5. **Start from the best checkpoint, not the latest.** Phase C (40% MASBENCH) > V2 SFT (20% MASBENCH).
